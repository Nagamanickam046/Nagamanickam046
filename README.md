**STAGE 1 — Solar Project Tracker**

Pulls live project data from APIs and plots defective solar panels on a real map. Built for field engineers who need to find faults fast. OpenStreetMap under the hood, paginated lists, deep linking so you can share a panel directly, clipboard copy for coordinates.

`Flutter` `Provider` `OpenStreetMap` `Deep Linking` `REST API`

<br/>

**STAGE 2 — Auth System**

Secure login and password reset built with Django. Email-based reset flow, token auth, plugged into Flutter on the frontend. Nothing flashy, just solid.

`Django` `DRF` `Token Auth` `Flutter`

<br/>

**STAGE 3 — Defect Panel Viewer**

Map and tab view working together — switch between map mode and list mode, update defect status live, add comments per defect. The kind of UI that looks simple but needs thought.

`Flutter` `OpenStreetMap` `TabBar` `Dynamic UI`
